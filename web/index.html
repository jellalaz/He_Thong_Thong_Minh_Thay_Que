câu lệnh.

  1. Chọn chủ đề

    Ví dụ HbA1c. Web đọc những quan hệ tương ứng từ Neo4j.

  2. Bấm một nút

    Nút là khái niệm. Đường nối mô tả quan hệ giữa hai khái niệm.

  3. Xem tài liệu

    Mỗi quan hệ đi kèm mã tài liệu để đối chiếu căn cứ.

Neo4j có tác dụng gì?

Nó lưu và truy vấn quan hệ. Khi chat tìm được tài liệu, hệ thống lấy thêm những quan hệ liên quan từ Neo4j để trình bày cùng căn cứ.

Neo4j không tự huấn luyện mô hình hay tự xác nhận kiến thức là đúng.

Mở Neo4j trên máy của tôi

Máy này đã có bản Neo4j cục bộ. Khi trạng thái báo kết nối, bạn có thể mở Browser và chạy truy vấn bên dưới.

Mở Neo4j Browser ↗
MATCH (a:Concept)-[r:RELATED_TO]->(b:Concept)
RETURN a,r,b LIMIT 100;

Nếu dịch vụ tắt: chạy start-neo4j.ps1 trong thư mục TIEULUAN_FINAL. Tài khoản cấu hình trong .env; không chia sẻ file này. Link localhost chỉ dành cho máy cài Neo4j.
